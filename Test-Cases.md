|---|---|---|---|---|
| TC-LOGIN-01 | `LoginPageTest.entersCredentialsAndSubmitsForm` | Test account is available. | Open the login page, enter the configured email and password, and submit. | Login completes and the authenticated dashboard is displayed. |
| TC-EVENT-01 | `CreateEventTest.logsInNavigatesToEventsAndCreatesConference` | Test account is available. | Log in, open event management, enter a unique conference title and valid event details, then submit. | The created event appears in the Admin events table. |

| TC-DETAIL-02 | `BookingDetailsTest.verifiesBookingDetailsAndCancellationFlow` (clear-all portion) | At least one booking exists for the test account. | Choose Clear all bookings and dismiss the browser confirmation; confirm the booking remains. | TC-ADMIN-01 | `ManageEventsByAdminTest.cancelsAndConfirmsDeletionForBothCreatedEvents` | Both named QA-created events exist in the Admin table, Dashboard, and Events page. | For each event, open Delete and cancel, then verify it remains in all listings. Open Delete again and confirm; verify removal from Admin, Dashboard, and Events page. | Cancel leaves both events unchanged; confirmed deletion removes each event from all three locations. |
